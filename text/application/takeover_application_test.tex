% 3 ABSTRACT
\meta{APPLICATION}{INITIAL CONDITION}\folio{03}\sidelegend
\vspace*{45mm}\hspace*{62mm}
\begin{minipage}{128mm}
  \sectionnumber{0}\par\vspace{1mm}
  {\displayfont\color{signal}\fontsize{24}{24}\selectfont INITIAL CONDITION.}\par\vspace{8mm}
  {\fontsize{12.5}{16}\selectfont
    A community gallery is offered through a competition. Many practices enter; one proposal is selected. This application begins by accepting that condition, then introduces one small perturbation: selection need not terminate the trajectories of the others.\\[5mm]
    We propose a photographic work that behaves as a living relation. Images lead to people. People bring voices, sounds, places, practices and further people. The exhibition is not conceived as a terminal object but as an activation surface.\\[5mm]
    This temporary text exists only to test hierarchy, density, rhythm and the transition between scientific argument, photographic evidence and invitation.
  }
\end{minipage}
